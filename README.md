# railwayfan.ro

This repository contains the source content for the railwayfan.ro website.

## About

The site focuses on:

- rail transport
- railway modelling

## Structure

- `rail-transport/` — rail transport content
- `railway-modelling/` — modelling content
  - `projects/` — Railway model projects

## Goals

- document railway modelling projects
- share progress photos and notes
- publish rail transport related content
- keep the site easy to update over time

## Notes

The content is organized in folders so it can be used with a static site generator or a simple custom website.
